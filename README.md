# Oman Maritime Agentic AI POC

Desktop Angular proof-of-concept for the Oman maritime service **Issuance of a Temporary Registration Certificate for the Ship or Marine Unit**.

## Working demo journey

Service Details → AI Assistant → Upload Evidence → AI Processing → AI Prepared Application → Resolve Exceptions → Review & Submit → Employee AI Review → Human Decision.

The UI follows the existing Oman maritime portal visual language shown in the project screenshots. This repository is a frontend POC: AI extraction, external checks and backend validation are simulated, while the UX explicitly keeps the authoritative platform business rules and final officer decision outside the AI layer.

## Run

Install dependencies and start the Angular development server using the scripts in `package.json`.
